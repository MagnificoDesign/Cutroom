# Cutroom Independent

First Lovable-free Cutroom package.

Implemented: installable PWA shell; no cloud video-analysis API; AES-GCM encrypted IndexedDB vault; 4 MB encrypted chunks; local video import; local Canvas frame sampling; spatial/edge descriptors; conservative temporal overlap detection; suggested ordering; high-confidence overlap trimming; ambiguous overlaps retained for review; individual encrypted-copy deletion; auto-lock on backgrounding; storage summary.

Not claimed yet: iPhone verification, finished MP4/H.264/AAC export, Face ID, security audit, semantic scene/story understanding, or perfect duplicate detection.

Once these static files are hosted over HTTPS, open the URL in Safari and use Add to Home Screen. The host serves app code; selected videos are processed by that code locally.
